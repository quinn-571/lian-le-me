# UI设计规范

## 设计原则
- **简洁直观**：信息层级清晰，减少操作步骤
- **移动优先**：touch target ≥ 44px，防误触
- **有温度**：暖色系 + emoji，不冷冰冰

## 组件规范
- **日历格子**：最小 60px 高度，触摸友好
- **底部导航**：高度 64px，固定底部，safe-area 适配
- **弹窗**：居中覆盖，半透明背景，点击外部关闭
- **按钮**：圆角 ≥ 8px，primary 使用主题色
- **emoji图标**：14px，项目名前点缀

## 交互动效
- 主题切换：即时无动画（CSS变量）
- 完成勾选：200ms 删除线过渡
- 庆祝动画：0.5s 大勾号弹跳 + 2s 撒花
- 长按触发：600ms hold

## 字体
- 系统默认字体栈：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei'`
- 日期数字：font-weight 500~700
