# 功能需求文档 — 练了么

## 产品定位
运动日历 PWA — 智能排课，轻松管理有氧无氧训练。

## 核心功能

### 1. 运动日历
- 默认显示今日，可切换本周/本月视图（传统格子日历）
- 日期下方展示运动课表，可回溯历史
- 有氧项目 → 主题有氧色，无氧项目 → 主题无氧色
- 经期日期 → 淡红色圆底标注
- 已完成项目 → 变淡 + 同色删除线
- 勾选完成 → 提示音 + 撒花 + 大勾号动画
- 仅可勾选今日及历史项目
- 长按删除项目

### 2. 手动调整课表
- 可删除/添加未来日期的项目
- 手动调整过的日期"锁定"，不参与自动排课
- 系统自动适配后续课表
- 可一键重置当天课表

### 3. 设置页
- 性别选择（男/女，影响后续设置项显示）
- 有氧/无氧一周频次
- 各项目一周次数
- 洗头日设置（仅女性）
- 经期信息（仅女性）
- 项目标记：大出汗/舒缓（带 ℹ️ 提示）
- 自定义运动项目（含emoji图标）
- 5套主题配色切换

### 4. 自动排课规则
1. 连续2-3天训练 → 至少1天休息
2. 一天最多1有氧+1无氧
3. 洗头日优先2个项目，优先大出汗
4. 同项目不连续两天
5. 同项目一周N练均匀间隔
6. 经期前3天休息，后续仅舒缓运动
7. 修改设置仅重排未来课表
8. 手动锁定日跳过排课
